# Contributing

Systead is not yet open for general external contributions. The repository structure is being stabilized before a contribution model is selected.

For now:

- use issues for clearly reproducible bugs or bounded proposals;
- do not submit private data, credentials, or unpublished user material;
- do not introduce cloud dependencies, telemetry, destructive automation, or external actions without an explicit architecture decision;
- preserve the separation between generic Systead code and private House configurations.
