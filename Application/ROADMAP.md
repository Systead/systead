# Roadmap

## Foundation — now

- Clean repository and organization structure.
- Public product language and brand candidates.
- Architecture decisions and privacy boundary.
- Empty/demo House configuration.
- Local validation and Git bootstrap.

## Systead Alpha 0.1.0

- Setup wizard.
- Local House creation.
- Module enable/disable.
- Core records, commands, review queue, audit, and backup.
- Generic Today, Work, Money, Contact Desk, Knowledge, and System areas.
- Portable export and restore.
- Product-boundary scan.

## AuthorMachine by Systead 1.0.0

- Publishing Studio.
- Catalogue, projects, manuscripts, canon, continuity, editions, rights, production, and release control.
- Publishing knowledge and AI-assisted review.
- No private Stokknes records in public packages.

## Later

- Native desktop shell.
- Optional encrypted sync.
- Mobile companion.
- Module SDK.
- Signed updates.
- Team and multi-House capabilities only after the single-operator model is stable.
