# Privacy Principles

Systead is designed to be local-first and operator-owned.

1. Data remains local unless the operator enables a specific external integration.
2. Private records are not promoted into public outputs without explicit approval.
3. AI-assisted extraction and suggestions enter a review queue before becoming canonical truth.
4. Telemetry is off by default and must remain optional and transparent if introduced.
5. Demo data must be fictional and must not be transformed private user data.
6. Export, deletion, archive, backup, and recovery must remain understandable to the operator.
