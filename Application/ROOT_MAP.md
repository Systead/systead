# Root Map

```text
Systead/
├─ apps/                     Application shells
├─ packages/                 Generic platform packages
├─ modules/                  Optional specialist products/modules
├─ config/                   Demo and local templates
├─ docs/                     Architecture and product truth
├─ site/                     Prelaunch website preview
├─ scripts/                  Validation and Git helpers
├─ tests/                    Automated and acceptance tests
├─ releases/                 Public release material
├─ archive/                  Retired public-product material
├─ github-org-profile-repo/  Files for Systead/.github
└─ .github/                  Main-repository automation/templates
```

The root should remain calm. Installers, generated packages, logs, backups, exports, and experiments must not accumulate beside the stable entry documents.
