# Systead Alpha Scope

## Include

- Empty or fictional demo House.
- Setup wizard and local data location.
- Configurable modules.
- Core record linking, commands, review, audit, backup, export, and recovery.
- Generic Today, Work, Money, Contact Desk, Knowledge, and System views.
- Safe Mode and Sensitive View.
- AI suggestions with source, reason, confidence, and approval controls.

## Exclude from Alpha

- Bank credentials and automatic payments.
- Automatic public publishing.
- Tax filing or regulated professional advice.
- Cloud accounts required for normal use.
- Telemetry enabled by default.
- Multi-user collaboration.
- Private Stokknes data or adapted versions of it.
