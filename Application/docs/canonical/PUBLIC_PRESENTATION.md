# Public presentation

Systead leads with the website design and build service. The homepage must show realistic scope, first-party work, delivery boundaries and the website estimator.

Software House and Programs are a secondary, explicitly early-stage direction. Do not describe the whole business as a software pre-alpha.

The website estimator uses provisional planning rates, not an approved rate card. It must distinguish one-off labour, client-paid suppliers, renewal costs and unknown prices. It creates a downloadable brief, not a booking.

Stokknes House is the founder’s private overarching workspace. Stokknes Publishing House is the separate personal imprint. Neither is a Systead software product. Private knowledge, effort checks and business records must stay outside this public repository.
