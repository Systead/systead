# Brand and naming

**Status:** Canonical working direction
**Effective:** 19 July 2026

## Parent brand

**Systead** is the active parent platform and brand.

It may be used publicly before the future company exists. Legal ownership and company identity must remain accurately described.

## Primary tagline

> **Local intelligence. Built for home.**

“Home” means the operator's owned ground: personal, household, professional, creative, and small-organisational work held inside one controlled House.

## Product descriptor

Preferred explanatory description:

> **A private continuity system for memory, decisions, responsibility, and long-lived work.**

Alternative descriptions may be used when context requires:

- local-first continuity and operations platform;
- operator-owned House for memory and controlled action;
- private institutional memory for an individual or small owner-operated organisation.

Do not lock an industry category merely for marketing convenience while the product model is still pre-alpha.

## House

A **House** is the configured operator environment.

Do not present “Systead House” as a separate parent product.

## Program 01

The first specialist Program serves publishing.

**Folio** is the current Program working name. **AuthorMachine** and **Stokknes OS** identify the broader private Stokknes House implementation lineage.

The final public release name is undecided.

Public references must avoid implying that:

- AuthorMachine is the permanent name;
- all visible private features will ship;
- Program 01 defines Systead;
- the private v10 interface is a public release build.

## House Steward

House Steward is a working name for the intelligence and assistance layer. The authority model is canonical; the name is provisional.

## Stokknes House

Stokknes House is the private flagship and proving ground across the founder’s whole operation. Stokknes Publishing House is the separate publishing imprint. Use **Publishing Program** for reusable software; reserve the qualified **Stokknes Publishing House** name for the imprint. “Publishing House” may remain a generic Program profile for a small press.

It is not a public product, template, seed dataset, or release identity.

## Company names

- **Systead Systems S.L.U.** — intended future platform company, not yet to be presented as an existing legal entity before incorporation.
- **Stokknes Publishing** — publishing lane and intended future publishing company, not the automatic owner of the general platform.

## Visual identity

The current Systead visual system combines:

- a dark flagship masthead with silver and restrained gold;
- a house-and-node emblem;
- calm warm product pages;
- generous spacing;
- clear editorial hierarchy;
- dark technical sections only where the content becomes technical.

The product must not become a Stokknes Publishing reskin.

Avoid:

- noir author imagery;
- book-cover atmosphere as the default interface language;
- heraldry;
- smoke, scars, chaos, or personal mythology;
- generic neon AI/SaaS graphics;
- cramped card walls;
- screenshot domination without explanation.

See [BRAND_ASSET_USAGE.md](BRAND_ASSET_USAGE.md).

## Voice

Public voice should be:

- plainspoken;
- serious;
- human;
- specific;
- calm;
- honest about maturity;
- ambitious without pretending implementation completeness.

Order the language:

1. human problem;
2. product benefit;
3. concrete experience;
4. feature depth;
5. system architecture;
6. honest status.
