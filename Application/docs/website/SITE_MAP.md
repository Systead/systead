# Future Systead Website Map

- `/` — clear product promise and Alpha status.
- `/product` — what a House is and how Systead works.
- `/principles` — local-first, operator control, reversibility, and AI policy.
- `/author-machine` — first specialist product.
- `/security` — data model, local storage, threat boundaries, and reporting.
- `/roadmap` — honest current stage and release gates.
- `/docs` — installation and product documentation when available.
- `/status` — current release maturity and known limitations.
- `/legal` — privacy, terms, trademarks, licensing, and AI transparency.

The prelaunch website should not claim public availability, production readiness, encryption guarantees, legal compliance, or features that have not passed acceptance testing.
