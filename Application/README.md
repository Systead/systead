# Systead

**Local-first command systems for running work, knowledge, money, household operations, and specialist workflows under human control.**

Systead is an early-stage platform architecture built around a configurable private environment called a **House**. A House brings records, projects, commands, review queues, knowledge, automation, and specialist modules into one controlled operating layer.

> Status: **Alpha foundation in preparation.** This repository is a product and architecture bootstrap, not a production release.

## Product family

- **Systead Core** — generic local-first records, storage, commands, safety, review, and audit.
- **Systead House** — the configurable command centre and user-owned environment.
- **AuthorMachine by Systead** — the first specialist product, focused on publishing operations.
- **Stokknes House** — the private proving ground; never shipped as public demo data.

## Principles

- Local-first by default.
- The operator owns the data and final decision.
- AI proposes; humans approve.
- Important actions are explainable, logged, and reversible.
- Private information is not silently promoted into public outputs.
- Modules link canonical records instead of cloning truth.
- No forced cloud, telemetry, publishing, payment, or external communication.
