
# Programs

A Systead **Program** is an optional specialist application operating inside a House.

Programs provide deep domain capability while sharing Systead Core foundations for identity, authority, provenance, decisions, privacy, audit, recovery, and export.

## The core distinction

> **Programs solve particular domains. Systead preserves the whole.**

Programs may define specialist records, workflows, dashboards, tools, imports, exports, and scoped intelligence.

Programs may not:

- redefine Systead's identity;
- own the operator's general memory;
- silently access unrelated Rooms;
- bypass Core permissions or command review;
- trap the House in undocumented structures;
- become required for unrelated House records to remain usable.

## Program 01: Publishing

The first Program serves authors and publishing operations.

Its current internal working name is **AuthorMachine**. This name identifies the private v10 line and current development discussions. It is not locked as the public release name.

The final release name, package boundaries, included features, price, licence, supported platforms, and release identity remain undecided.

Publishing is the first proving domain because it combines long-lived projects, versions, canon, research, decisions, rights, contacts, production, editions, release, and correction history.

It demonstrates how deep a Program can become. It does not define the limits of Systead.

## Future Programs

The architecture should support additional specialist domains. Examples may be discussed to test the model, but they are not announced products or release commitments until explicitly approved and documented.
