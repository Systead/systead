
# Programs

A Systead **Program** is an optional specialist application operating inside a House.

Programs provide deep domain capability while sharing Systead Core foundations for identity, authority, provenance, decisions, privacy, audit, recovery, and export.

## The core distinction

> **Programs solve particular domains. Systead preserves the whole.**

Programs may define specialist records, workflows, dashboards, tools, imports, exports, and scoped intelligence.

Programs may not:

- redefine Systead's identity;
- own the operator's general memory;
- silently access unrelated Rooms;
- bypass Core permissions or command review;
- trap the House in undocumented structures;
- become required for unrelated House records to remain usable.

## Program 01: Publishing

The first Program serves authors and publishing operations.

Its current working name is **Folio**. AuthorMachine identifies the broader private Stokknes House lineage from which publishing workflows are extracted. The Publishing Program is software; Stokknes Publishing House is the founder’s publishing operation. Neither the private House nor the imprint is the Program itself.

The final release name, package boundaries, included features, price, licence, supported platforms, and release identity remain undecided.

Publishing is the first proving domain because it combines long-lived projects, versions, canon, research, decisions, rights, contacts, production, editions, release, and correction history.

It demonstrates how deep a Program can become. It does not define the limits of Systead.

## Program 02: Shared Home

Shared Home is the resident-side focus Program for solo homes, families, co-renters, shared households, and renters.

Its internal pre-alpha codename is **Hearth**. It focuses on people, agreements, services, shared costs, maintenance evidence, inventory, responsibility, and handover without claiming payment, legal, surveillance, or landlord authority.

## Program 03: Property Steward

Property Steward is the owner-side focus Program for owner-occupiers, small landlords, and property stewards.

Its internal pre-alpha codename is **Keystone**. It focuses on properties, units, tenancies, condition, inspections, maintenance, vendors, documents, obligations, costs, and handover.

Shared Home and Property Steward may refer to the same building or maintenance issue only through explicit links and visible authority. A resident's household is not the owner's asset register.

The separately planned website service is commissioned work, not a House Program. See [Systead and Stokknes](SYSTEAD_AND_STOKKNES.md).

## Commercial direction

The intended product shelf is:

- a useful free Systead application and local House;
- optional specialist Programs purchased once;
- a one-time full-suite option;
- no monthly subscription or consultancy dependency;
- readable export and continued local use for the purchased build.

Nothing is currently available for public download, purchase, or supported use. Price, licence terms, final names, and Program boundaries remain undecided.
