# Status and scope

**Status date:** 25 July 2026
**Maturity:** Running private pre-alpha
**Public access:** Closed

## What exists

A private flagship Systead House is running under real daily use.

The current private line contains broader House capabilities and the first specialist publishing Program at varying levels of completeness. A separate synthetic local browser run now exercises the House loop across the three focus directions: Publishing, Shared Home, and Property Steward.

## What is being tested

- data integrity;
- duplicate and conflicting truth;
- startup and persistence;
- indexing;
- commands and review;
- private/public boundaries;
- backup and restore;
- migrations;
- external effects;
- recovery;
- progressive disclosure;
- separation between Core, private House configuration, and Program 01;
- resident-side Shared Home and owner-side Property Steward contracts without authority leakage.

## What is not available

- supported installer;
- public tester package;
- final Program 01 name;
- final feature contract;
- stable migration promise;
- production-security guarantee;
- public support agreement;
- release date.

## Screenshot rule

Public interface studies use synthetic or deliberately sanitized data.

Private v10 screens may later be shown as explicitly labelled internal working-build evidence, but they must not expose private records or imply that every visible feature will ship.

## Naming rule

Systead is the platform brand.

AuthorMachine is the current internal working name for the publishing Program and private v10 line. The public release name remains undecided.
